Apontamento: três ajustes

Protótipo dos três ajustes juntos. Dados fictícios, nada é gravado. Digite algo numa máquina e tente sair de três jeitos para ver a confirmação.

  • 1. Cartão em duas colunas: contexto à esquerda, o que se digita à direita
  • 2. Lista de máquinas ao lado com linhas de 44px
  • 3. Confirmação de saída também para mudanças de rota feitas pelo sistema
